# AI っぽい表現の2つの型

todesking「スロップ表現100連発」(https://zenn.dev/todesking/articles/5bc43f449ecdf6) の分類をもとに、判定に使う形へまとめ直した。例文は説明のために作ったもので、元の記事の例ではない。

## 意味破綻型

次の3つをすべて満たす表現。

1. 読み流すと自然に見える。言いたい雰囲気は伝わる。
2. 字義どおりに読むと成り立たない。主語・述語・修飾の関係をそのまま取ると、意味が通らないか、現実と合わない。
3. その文だけで不自然だと分かる。前後や専門知識と照らさなくてよい。

例: 「通知の音が、会議室の空気を静かに折りたたんだ」(空気は折りたためない)、「データが議論の輪郭をやわらかく整えた」(データは何も整えない。誰が何をしたかが消えている)

物や概念を主語にして人の動作をさせる文と、比喩の動詞 (刺さる・溶かす・効く・響く・浮き彫りにする) で中身を言わずに済ませる文が、この型になりやすい。

## 過剰圧縮型

短く言い切ろうとして情報を省きすぎ、意味が1つに決まらなくなった表現。字義どおりに読んで矛盾するとは限らない。次のどれかに当たる。

- 省きすぎ: 省いた要素を補おうとしても、補い方が1つに決まらない。例: 「受付と完了を分ける」(何の受付を、どう分けるのか)
- 動詞の独自用法: 動詞をその文だけの意味で使っている。例: 「障害は仕組みで返す」
- 主題と述語の不一致: 「〜は」で示した主題と述語がかみ合わない。例: 「新人は出社を厚くする」

スライドの見出し、行動指針、標語のように、短く言い切る場所で出やすい。

## 判定するときの注意

- 意図して使った比喩や、文学的な表現として働いている所は当たらない。漫然と並んでいるものだけを挙げる。
- 業界で定着した言い方 (「ボトルネック」「スコープ」など) は当たらない。
